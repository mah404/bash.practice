# Docker Compose Replicas - Beginner Loesung

Dieser Ordner enthaelt die Loesung fuer das Aufgabenblatt zu Replicas mit Docker Compose.

## Dateien

- `01_docker-compose_simple.yml` - Aufgabe 2 und Aufgabe 7: einfache Compose-Datei ohne festen Port
- `06_docker-compose_fixed_port.yml` - Aufgabe 6: Compose-Datei mit festem Port
- `befehle_mit_erklaerung.sh` - Aufgabe 1 bis 10: alle wichtigen Befehle mit englischen Kommentaren
- `antworten.md` - Aufgabe 1 bis 11: schriftliche Antworten zu den Aufgaben

## Wichtig

Die Datei `befehle_mit_erklaerung.sh` ist als Lernhilfe gedacht.
Fuehre sie nicht komplett auf einmal aus.
Besser ist: Befehl fuer Befehl lesen und im Terminal testen.
