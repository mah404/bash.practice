# Git Branches Hausaufgabe Loesung

Dieser Ordner enthaelt fuer jede praktische Aufgabe ein eigenes Skript.

## Wichtig

Die Skripte fuehren echte Git-Befehle aus:

- Branches erstellen
- Dateien schreiben
- Commits erstellen
- Push zu GitHub ausfuehren
- Merges durchfuehren

Fuehre sie nur in deinem geklonten Hausaufgaben-Repository aus.
Nicht direkt in diesem Sammelprojekt starten.

## Reihenfolge

1. `01_repository_vorbereiten.sh`
2. `02_grundstruktur_erstellen.sh`
3. `03_branch_begruessung.sh`
4. `04_merge_begruessung.sh`
5. `05_branch_menue.sh`
6. `06_merge_menue.sh`
7. `07_branch_case_auswertung.sh`
8. `08_merge_case_auswertung.sh`
9. `09_readme_ergaenzen.sh`

## Finale Dateien
